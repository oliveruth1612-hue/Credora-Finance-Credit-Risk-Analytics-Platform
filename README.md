# 💳 Credora Finance Credit Risk Analytics Platform

A Machine Learning-based Credit Risk Analytics Platform that predicts loan approval and analyzes customer credit risk using Python, Random Forest, and Streamlit.

---

## 📖 Project Overview

The Credora Finance Credit Risk Analytics Platform is designed to assist financial institutions in making data-driven loan approval decisions. It analyzes customer financial information and predicts whether a loan application should be approved based on historical credit data.

The project includes an interactive Streamlit dashboard, machine learning model, data visualization, and credit risk analysis.

---

## ✨ Features

- Loan Approval Prediction
- Credit Risk Analysis
- Interactive Streamlit Dashboard
- Customer Data Visualization

- Random Forest Machine Learning Model

## ⚙ Installation

### Clone the Repository

```bash
git clone https://github.com/oliveruth1612-hue/Credora-Finance-Credit-Risk-Analytics-Platform.git
```

### Move into the Project Folder

```bash
cd Credora-Finance-Credit-Risk-Analytics-Platform
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶ Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your browser.
